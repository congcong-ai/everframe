## 本机录像与保存

EverFrame 不提供账号、订阅、云端存储或自动同步。基础录像由用户在应用前台手动启动；摄像头和麦克风仅用于生成用户设备上的视频及音轨。Android 在用户主动开始后可使用 camera|microphone 前台服务继续录像；iOS 离开应用或锁屏会停止录像。原始视频和录音不会自动上传到 EverFrame 服务。

录像、素材信息、导入的转写和分析结果保存在本机应用数据目录。循环存储会按用户设置清理未保护的旧片段；用户也可在素材页删除片段。删除片段会一并删除其关联转写和分析，但已生成的每日总结可能作为历史内容继续保留。Android 允许用户在设置中分别移除 DeepSeek、OpenAI、Anthropic 或自定义服务的 API Key；各 Key 使用 Android Keystore 加密保存，并排除系统备份。卸载应用会删除应用私有数据；重要录像请先导出到用户选择的位置。

## 可选联网功能

### Android 可选文字分析

AI 默认关闭。用户主动启用并确认后，应用尝试在设备端处理转写。用户配置或测试自己的 API Key，或启动文字分析时，应用会通过 HTTPS 将该 Key 和请求内容直接发送到当前选定的服务：DeepSeek、OpenAI、Anthropic，或用户填写的 OpenAI Chat Completions 兼容接口。内容可能包括带时间戳的转写、片段摘要、每日总结所需摘要，以及测试连接提示。自定义服务会收到用户填写的 API Key 与请求内容；启用前请核对主机地址并确认服务可信。EverFrame 不接收这些数据；原始视频和录音不会发送给上述服务。此功能不是基础录像所必需，用户可以不配置 Key、不启用 AI。请求的处理、保留和费用受用户所选服务商的条款约束。更换服务商或自定义接口会关闭 AI，并要求用户重新确认。

Android 的系统文件转写是默认关闭的实验功能，只尝试本机系统识别，不会自动回退到在线识别；其可用性取决于设备和已安装的识别服务。

### iOS 在线语音识别

iOS 优先使用设备端语音识别。只有在设备端不可用且用户另行同意在线识别时，相关音频才可能由 Apple 处理。该路径不适用于 Android。

### iOS 可选文字分析

AI 默认关闭。用户主动启用并配置自己的 DeepSeek API Key 后，应用会通过 HTTPS 将该 Key 随请求直接发送至 DeepSeek。片段分析请求包含带时间信息的转写文字；每日总结请求包含已经生成的片段摘要；测试连接会发送 Key 和测试提示。EverFrame 不接收这些请求。原始视频、音频和关键帧不会发送给 DeepSeek。Key 保存在 iOS Keychain，用户可以在设置中删除。

DeepSeek 当前公开的 [Open Platform 条款](https://cdn.deepseek.com/policies/en-US/deepseek-open-platform-terms-of-service.html) 将 API Key 视为调用凭据，并要求开发者在服务前向最终用户披露数据处理规则。[DeepSeek 隐私政策](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html) 说明输入可能用于提供、开发和改进服务（包括模型训练），并可能在账户存续期间或为法律及业务需要保留；政策还说明个人数据可能在中国处理和存储。具体适用条款、处理、保留和费用以用户实际使用时服务商公布的政策为准。请勿发送敏感信息或未经授权的第三方内容。

### 局域网电脑控制

用户主动开启电脑控制并完成配对后，同一 Wi-Fi 网络中的配对电脑可以读取录像状态、磁盘信息、片段 metadata 和分析摘要，也可以按应用支持的操作控制录像。此连接只在本机和局域网内建立，不经过 EverFrame 云端；协议使用未加密的 HTTP，只适合可信 Wi-Fi，设置页会提示该限制。离开前台后，服务会停止并清除会话。

### 导出和分享

录像导出或分享由用户主动发起，并由用户在系统文件选择器或分享面板中选择接收位置或应用。文件离开设备后的处理方式由用户选择的目标服务决定。

## 诊断、广告与联系

EverFrame 不集成广告或用户行为分析 SDK，不向开发者服务器发送诊断日志。局域网控制、AI 和导出分别按上述功能触发。

如对隐私或数据处理有疑问，请联系 [info@xixisys.com](mailto:info@xixisys.com)。EverFrame 没有用户账号或开发者云端素材库；应用内素材删除、Key 移除和卸载的边界见本政策。
