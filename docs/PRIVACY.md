# 隐私

原始视频默认且始终保存在本机。没有云端账号、后台服务、上传视频或自动同步。录像只在用户明确点击开始后启动，界面持续显示 REC；切后台停止。

AI 默认关闭。开启后，带时间戳的转写发送至用户设置的 DeepSeek API；每日总结只发送已生成片段摘要。关键帧发送未实现，不会静默上传图片。原视频、音频不发送 DeepSeek。

Apple Speech 优先设备端；如果不能本地识别，用户必须另外确认允许 Apple 在线识别，音频才可能被 Apple 处理。Speech 系统授权与这个 App 内隐私开关相互独立。

局域网控制需要用户开启、允许系统本地网络权限、输入配对码，并在以后使用令牌。状态、磁盘信息、片段 metadata、转写衍生摘要会向已配对电脑显示。不提供互联网远程控制，不访问电脑文件。HTTP 明文可能被不可信网络窃听，设置页已提示。

Key 保存在 ThisDeviceOnly Keychain；JSON 与日志不含 Key。开发环境变量仅 Debug 可用。日志只包含固定事件，没有完整转写、AI 原文、配对码、令牌或敏感请求响应。Debug 的 AI JSON 页面可能包含个人内容，只在本机主动查看。

Documents 提供 Finder 文件共享以便用户备份；连接受信任电脑后可能读取该目录。录像目录排除系统自动备份。手动分享原录像由系统分享面板处理，目标由用户自行选择。

删除片段会删除相应转写与分析；已生成每日总结独立保存，可能还含删除前的概括。卸载会删除 App 容器；Keychain 可能随系统策略保留，因此不要把卸载视作可靠撤销 Key 的手段，可先在设置中删除 Key。未选择 License，不包含第三方分析或广告 SDK。
