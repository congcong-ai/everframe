# Android 真机验收手册

先运行 `./scripts/android.sh check`。JVM测试覆盖规则、JSON、配对和真实本机TCP；Lint和编译检查API与资源。它们不能证明Camera HAL、音频、视频封装、长时稳定性或系统语音服务正确。所有硬件项在验证记录中独立填写，未执行不能打勾。

## 安装与最小闭环

1. 连接Android真机，开启开发者选项、USB调试并确认电脑授权，执行 `./scripts/android.sh doctor`、`./scripts/android.sh install`。保留已有数据更新安装，不卸载排错。
2. 初始不配置Key、无网络、AI关闭。拒绝摄像头或麦克风，确认不创建假成功素材；允许后后置录像一分钟，确认REC、计时与停止。
3. 素材播放首、中、末，听到同期讲话；导出原MP4至文件，再复制电脑检查。可用 `ffprobe -v error -show_streams -show_format 导出文件.mp4` 查看真实音轨、视频轨、尺寸、时长与编码，播放确认方向与音画同步。不要仅依赖元数据存在就认定声音正常。
4. 切前置再录一分钟：预览、保存画面的镜像行为、文字方向、导出文件与音频独立检查。设置页改变5/10/15/30分钟后检查持久化。
5. 默认字体与最大辅助字体、窄屏、手势导航检查四页、REC与停止入口；切换功能页不能中断已开始的录像或偷偷重绑摄像头。

## 分段与停止竞争

Debug设置30秒/60秒分段，连续十分钟。导出所有片段逐段检查音画、时长、文件大小，记录相邻片段间隙。

在准备、自然分段保存、下一段刚开始时分别点停止；快速开始/停止十轮。停止后的Finalize回调不能再次续录；正在保存时停止应取消下一段且继续等待原文件封装。双录与切镜头在录像中应提示先停止，不擅自中断。

录像中打开系统麦克风隐私开关、其它摄像头应用、来电、锁屏、切后台，确认明确停录或告警；返回前台不会自动重新开始。系统强杀后重新打开应扫描恢复，不能把损坏文件当正常可分析素材。

## 循环与保护

使用没有个人内容的测试素材，将配额调到0.3GB、分段30秒、剩余目标设为适合测试设备的数值。不要用填满真实系统盘方式测低空间，Debug可触发“模拟低磁盘停止”。

1. 先录几段、保护最老段，再继续直到触发清理。验证按最旧未保护优先，写入中、已保护、pendingLock均保留。
2. 各测10/30/60分钟保留，覆盖部分相交、恰在边界、当前段，立即退出再检查保护持久化。当前段完成后pendingLock转locked，不被旧回调覆盖。
3. 打开正在播放的旧段，另录新段触发清理；播放/分析/导出中的引用不得被删除。导出文件选择器取消后应释放临时引用。
4. 保护过多不能强制删除它们。删除保护素材必须确认；未确认不删除。模拟低空间后停止并保留原文件，不自动续录。
5. `adb shell run-as com.everframe.app ls files/EverFrame/Clips` 可检查Debug私有目录。要读取某个JSON时用run-as加文件名，不上传包含私人内容的文件。拔线或强杀恢复只能在可丢失的测试录像上执行。

## 电脑控制

开启开关、同一可信Wi-Fi，电脑用页面地址和配对码操作开始/停止/保留、素材保护与取消、时间轴和总结。首次开始必须已在手机授予权限；没有权限返回错误，不能显示已开始。

用curl实测匿名GET status与修改返回401、错误配对五次后冷却、冷却后正确码成功、旧会话在重开/后台后401；跨源POST应403。切换Wi-Fi后地址更新，旧监听关闭。关闭开关/后台/critical温度时无法控制。不要为公共Wi-Fi访问失败关闭认证。

示例（将IP替换成手机设置页值，令牌只保存在临时shell变量，不写源码）：

```sh
curl -i http://手机IP:8080/api/status
curl -i -H 'Content-Type: application/json' -d '{"code":"手机显示的六位码"}' http://手机IP:8080/api/pair
```

## 转写：必须证明实际消费文件

在Android14+且提供端侧服务的设备安装系统离线中文模型；其它系统/设备明确显示缺失能力。实验系统转写默认关闭，先用共享样例修改为真实clipID导入，再验证文字分析。

要验收系统转写，在测试录像内说“A：这是文件中的内容”，于第55秒前后说带秒数的句子。录完后，在环境里持续说“B：这是环境声音”，再启用实验转写：结果必须只来自A，不能包含B。分别断网与联网测试，证明端侧中文可用、不自动依赖网络。若识别器忽略文件输入，此项失败，关闭实验功能，不得标记完成。

检查跨55秒块偏移，词级起点应落回实际录像秒数；相邻词开始构成展示区间，最后词结束取块边界，不要求虚构精确词尾。服务不提供时间戳、中文模型未安装、文件输入不支持、拒绝权限、取消、超时、无人声均必须明确失败，不生成假摘要。检查cache中的speech临时文件完成/失败后清理，强杀残留下次启动清理。

## AI 与总结

用户自行输入测试Key，不放到仓库。启用AI前明确同意仅文字外发。测试正确/错误Key、模型、余额不足、断网、超时、非法JSON、越界时间与未知UUID。错误只使当前分析失败，录像仍可独立开始。录制中、后台、发热时分析暂停，已完成转写可复用；重试不伪造识别。

至少3段不同主题、已完成分析的当天素材，生成每日总结，校验只基于已有摘要且引用真实原片段；时间轴点击定位正确秒数。重启后分析与总结可读；删除原片段后总结保留历史快照，不能播放不存在的视频。API Key和完整转写不出现在日志/网页。

## 双摄与温度

不支持并发的手机点击双录应明确提示、保留单镜头可用。兼容设备检查实际前后组合、绑定失败降级、单个MP4上下画面、比例/裁切、文字方向、音轨、同步、切段与保护、预览和导出一致。旋转、切后台、首帧前停止、麦克风隐私开关、系统摄像头占用均需测试。没有兼容设备不能宣布双摄通过。

双录温度和功耗更高。温度severe暂停分析，critical停Web，emergency请求停录像；系统可能更早中断，不通过强制负载使设备严重过热。

## 长时稳定性

单摄纯录像 → 加Web → 加AI → 双摄分别做2/4/8小时，接电、固定摆放、保持前台，不锁屏。每轮填表并抽查首、中、末文件。
